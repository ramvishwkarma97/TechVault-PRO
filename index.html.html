Linux Fundamentals — File System & Core Commands
FREE▼

Linux is a free and open-source Unix-like operating system kernel. Understanding the Linux file system hierarchy is the foundation of all system administration work.

Key Concept: Everything in Linux is a file — including devices, processes, and even directories.

File System Hierarchy (FHS):

/ → Root directory (top of the tree) /bin → Essential user binaries (ls, cp, mv) /etc → Configuration files /home → User home directories /var → Variable data (logs, spool) /tmp → Temporary files /usr → User programs and data /proc → Virtual filesystem (kernel/process info) /dev → Device files

Essential Commands Every Engineer Must Know:

ls -la # List all files with permissions pwd # Print working directory cd /path # Change directory mkdir -p a/b/c # Create nested directories rm -rf dir/ # Remove directory recursively cp -r src/ dst/ # Copy files/directories chmod 755 file # Change file permissions chown user file # Change file ownership
Pro Tip: Use man command to read the manual page for any command. Example: man ls

Top Linux Commands — Process, Memory & System Monitoring
FREE▼

System monitoring is a critical skill for Linux administrators and DevOps engineers. These commands help you understand what's happening on your system in real-time.

top # Interactive process viewer (CPU/MEM live) htop # Enhanced process viewer (better UI) ps aux # List all running processes ps aux | grep nginx # Find specific process kill -9 PID # Force kill process by PID killall nginx # Kill all processes by name

Memory & Disk Commands:

free -h # Show RAM usage (human readable) df -h # Disk space usage du -sh /var/* # Directory size breakdown vmstat 1 # Virtual memory stats every 1s iostat -x # I/O statistics
Interview Tip: top command — press M to sort by memory, P for CPU, k to kill a process directly.
uptime # System uptime and load averages uname -a # Kernel version and system info hostname # Show system hostname lscpu # CPU architecture details lsblk # List block devices
